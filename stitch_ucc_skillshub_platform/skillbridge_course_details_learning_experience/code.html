Takeaway 2

Dynamic year-over-year growth calculation using the DAX CALCULATE and SAMEPERIODLASTYEAR functions.

code DAX Measure: YoY Growth Percentage 
YoY Growth % = 
VAR CurrentSales = SUM(Sales[Revenue])
VAR PriorSales = CALCULATE(
    SUM(Sales[Revenue]), 
    SAMEPERIODLASTYEAR('Calendar'[Date])
)
RETURN
DIVIDE(CurrentSales - PriorSales, PriorSales, 0)
